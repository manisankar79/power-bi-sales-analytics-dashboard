Power BI Sales Analytics Dashboard
Project Overview

This project is an interactive, 5-page Power BI dashboard designed to analyze sales performance and generate meaningful business insights.

Dashboard Pages
Sales Overview – Key performance indicators, sales trends, and target analysis.
Sales Analysis – Monthly sales, channel performance, and category-wise comparisons.
Product Analysis – Product performance, profitability, and key influencing factors.
Regional Analysis – Geographic sales and profit analysis.
Business Insights – Top-performing cities, products, brands, and sales trends.
Tools & Technologies
Microsoft Power BI
DAX
Data Visualization
Interactive Slicers and Filters
Business Intelligence
Key Features
Interactive dashboard with five report pages
KPI cards for sales, profit, orders, and profitability
Sales trend and target analysis
Product, category, and regional performance analysis
Interactive filters for exploring business data
How to View the Dashboard
Download the dashboard.pbix file from this repository.
Open it using Microsoft Power BI Desktop.
Explore the five report pages and interact with the available filters.
